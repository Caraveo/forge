---
title: Keyboard and mouse
---

| Action | How |
| --- | --- |
| Send a message | **Enter** |
| Show or hide the build log | **Ctrl + L** |
| Rotate a model | Drag it |
| Zoom a model | **Ctrl** + mouse wheel, or **Zoom in** / **Zoom out** |
| Reset the view | **Reset** |
| Attach a file | Click **+**, or drag the file onto the window |
| Clear an attachment | Hover the chip and click the red **×**, or **Tab** to the **×** and press **Enter** |
| Pick a suggested project name | Click it, or type a name and press **Enter** |
| Jump to a project | Click its job card |
| Open an image | Click it in the conversation |
