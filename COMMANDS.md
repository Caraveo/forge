# Model Forge commands

`forge "a small forest cat"` builds a 3D model through the full local dimension workflow.

`generate "a small forest cat" --out cat.png` generates an image with the existing local image pipeline.

`enhance "a small forest cat"` runs the local AMD/ROCm prompt compiler and prints the enhanced 3D prompt.

The supporting `dimension`, `infer`, `background`, and `transit` commands remain available internally.
